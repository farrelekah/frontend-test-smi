## Frontend Test - Product Explorer

Aplikasi web sederhana untuk menampilkan daftar produk. Proyek ini dibangun untuk memenuhi instruksi Coding Test Frontend Engineer. 

## Deskripsi Aplikasi
Aplikasi ini memiliki fitur simulasi login sederhana dengan validasi. Setelah login berhasil, aplikasi akan mengambil data produk dari REST API (DummyJSON) menggunakan `fetch` dan menampilkannya dalam format grid card. Aplikasi ini juga menangani state loading, error, dan empty data.

## Bahasa Pemrograman & Tools
HTML5: Struktur semantik halaman.
CSS3 (Vanilla): Styling responsif menggunakan Grid dan Flexbox.
JavaScript (Vanilla JS): Seluruh logic aplikasi, termasuk penanganan state, interaksi DOM (Document Object Model), Fetch API, dan simulasi login, dibangun 100% menggunakan native JavaScript tanpa framework.

## Cara Menjalankan Aplikasi
Aplikasi ini sepenuhnya statis (Client-side), sehingga tidak memerlukan instalasi backend atau dependencies npm.
1. Clone repository ini ke komputer lokal Anda.
2. Buka folder proyek.
3. Klik ganda pada file `index.html` untuk membukanya di browser apa pun (Chrome, Edge, Firefox).
4. Masukkan email (menggunakan @) dan password apa saja untuk melewati halaman login.
